# 🗺️ SafeMap

**SafeMap** is a project that bridges the gap between technology and public safety. It was conceived as a mapping and utility tool, designed to help users visualize safety-related data through interactive maps.

## 🎯 Objective
To provide a clear, intuitive interface that allows users to identify safety-related areas and points of interest using geolocation and data integration.

## 🛠 Technologies & Concepts
* **Software Engineering:** Applied to architectural planning and design.
* **Geolocation:** Focused on map APIs and spatial data.
* **IA-Assisted Development:** Accelerated development supported by AI tools for logic and interface design.

## 📌 Status
Project currently in the prototyping and feature expansion phase.
